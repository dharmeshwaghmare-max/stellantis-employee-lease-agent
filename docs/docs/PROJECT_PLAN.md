# Stellantis Agentic Employee Lease Update System

## Purpose
Build a secure application to consolidate ORIX employee lease application updates and communicate verified progress to employees.

## Core features
- Employee and lease application tracking
- ORIX Microsoft Forms response integration
- Daily tracker synchronisation
- Detection of new and changed application statuses
- Employee matching using approved unique references
- Automatic routine, verified email updates
- Human approval for sensitive communications
- Duplicate email prevention
- Communication and synchronisation audit history
- Management dashboard and exception queue

## Communication policy
- Check the authorised tracker once daily.
- Automatically send only approved categories of routine, verified updates after integration testing and company authorisation.
- Require human approval for sensitive, conflicting or unclear updates.
- Never invent ORIX application statuses or promised dates.

## Development phases
1. Repository and application foundation
2. Backend and secure database
3. Employee and application dashboard
4. ORIX Forms integration
5. Daily monitoring agent
6. Email decision and approval workflow
7. Authorised Microsoft 365 email integration
8. Testing, security review and deployment

## Security
Use fictional test data during development. Do not commit employee personal information, ORIX files, credentials, access tokens or company-confidential information. Production use requires approved hosting, identity, data access and email permissions.

## Current status
Planning stage. External integrations and real email sending are not active.
